# InsectLabs Design Resources

User-provided visual assets collected for use and reuse across Insect Laboratories projects. Canonical module archives retain their own release snapshots. This shared folder keeps reusable source art in one place; it is tracked in the InsectLabs Git repository.

- `Burroughs_Logo.png` — user-provided Burroughs maker mark used by Model 62.
- `model62_hero.png` — approved Model 62 panel reference for the v1.0.0 release.
- `wireframe_globe_E8E8E8.svg` and `.png` — user-provided wireframe artwork and raster export used on the Model 62 panel.
