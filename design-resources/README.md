# InsectLabs Design Resources

Shared user-provided artwork, logos, diagrams, and source references collected for reuse across Insect Laboratories projects. Canonical module archives retain their own release snapshots; this folder preserves reusable originals and reference material.

The archive currently includes InsectLabs and refuge branding, the Burroughs maker mark, Poppy artwork, tube and globe diagrams, and the original Moffenzeef mixer schematic and quick-start PDF in `rm1010-mixer-references/`. Module-specific artwork remains with its module when it is needed to identify a release or reproduce a panel.

The nested RM1010 reference folder documents the source and intended use of those mixer references. No third-party licensing terms were supplied with the reference assets. The repository license governs only InsectLabs-authored code unless otherwise stated.
