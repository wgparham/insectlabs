# RM1010 mixer design references

These source documents were collected while developing the RM1010 Mixing Amplifier, the final compact mixer design for Wardenclyffe Station. They are preserved as historical design references; RM1010 supersedes the earlier minimixer concept, which is no longer a separate project.

- `MOF-MIX-QS.pdf` — Moffenzeef modular mixer quick-start guide.
- `moffenmix-schem.bmp` — Moffenzeef mixer schematic reference.

The RM1010 also considered Alice 28-series mixer references; these two files are the local reference documents retained here.
