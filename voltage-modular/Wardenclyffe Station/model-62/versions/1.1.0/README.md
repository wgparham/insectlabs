# Model 62 v1.1.0 — canonical release

Approved in Designer by the user on 2026-10-11. High Fidelity remains the default; War-Worn adds playback character and writes extra wear into new recordings. The standard 2500 buttons now retain their visible state correctly; mode selection is saved with the recording and older wire states remain compatible.

See the [User Manual](USER-MANUAL.md), [Developer Notes](DEVELOPER-NOTES.md), and [Release Review](REVIEW.md). The source pair is `model62.java` / `model62.vmod`; artwork and reproducible checks are included. `versions/1.0.0` remains the previous immutable archive.
