# 1998/4 Dynamic Modulator — Version 2.0.1

Canonical Wardenclyffe Station release for Voltage Modular.

This user-tested update extends the envelope DELAY to 0–5 seconds and raises the input amplifier ceiling to 16× for quiet sources. The delay taper and the remaining detector, gate, balance, and signal-through behavior are retained.

The matching Designer project and exported Java source are `nineteenninetyeight.vmod` and `nineteenninetyeight.java`. Module Notes read `v2.0.1`. The panel artwork and complete operating guide are included. Version 2.0.0 and the original 1.0.0 release remain preserved in the version archive.
