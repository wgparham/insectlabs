# LM-21 Mk III Matrix Mixer

**Canonical release: v1.1.0**, canonized at the user’s request on 2026-10-10. LM-21 is a 4×4 mono matrix mixer with independent row tone, character and reverb, plus a dry LINK submix into FULL MIX. Its 2D switch can send LINK through the shared channel D reverb; the wet return appears at D and in FULL MIX.

Automated source, build, and routing checks passed. The user also compiled, ran, and audio tested the exact v1.1.0 pair. Host CPU profiling is not recorded.
