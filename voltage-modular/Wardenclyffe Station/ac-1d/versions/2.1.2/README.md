# AC/1D SQR/SIN Function Generator · Version 2.1.2

Canonical Wardenclyffe Station release for Voltage Modular.

This release contains the tested 2.1.2 Designer project and matching Java export, the final panel artwork, its user manual, and the module review record. The previous 1.x release remains preserved at `../1.0.0/`.

The 2.x candidate behavior was built and auditioned by the user before this standards and packaging pass. This pass updates release naming, Designer identifiers and human-readable Display Names, version Notes, tooltips where they were missing, and documentation. It does not intentionally alter approved DSP behavior.

Open `ac1d.vmod` in Voltage Module Designer. Its exported source is `ac1d.java`.

See [USER-MANUAL.md](USER-MANUAL.md) for signal flow, control behavior, defaults, examples, and bypass behavior. See [REVIEW.md](REVIEW.md) for build and integrity checks. `SHA256.json` covers all release files except itself.
