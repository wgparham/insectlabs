# Sherlock 1.0.0 — canonical release

User-approved dual slew generator for Voltage Modular. Independent positive and negative
signal paths, patch-programmed feedback, FAST/SLOW ranges differing by exactly 1000, and
5/10 V positive START/SUSTAIN contours. First canonical release; approved sound and timing retained.

Defaults: Positive FAST near C4; Negative SLOW near C−1; both VC attenuverters zero; generated peak 5 V.
Build from this pair. The early sketch in references is historical material.
