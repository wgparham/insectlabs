# RM1010 Mixing Amplifier

**Canonical v1.0.0**, approved for canonization after successful code review/cleanup/checks on 2026-10-08. Four mono channels provide unity-to-2/5/100× input drive, 900 Hz tonal balance, volume and post-volume PROCESS sends. Outputs 3 and 7 are independent pair sums; 10 adds both pair sums, RETURN and LINK. S is the summed effects send.
