# HSB 1.0.1

Unmodified user-tested reference snapshot, archived 2026-09-28.

The `.vmod` is the Voltage Module Designer project; the `.java` is its source export. The hero PNG is the supplied panel image. `SHA256.json` records all three file hashes.

HSB switch compatibility: this submitted snapshot initializes the switches up (1), but its DSP interprets 1 as CUSTOM. The canonical 1.0.2 release corrects up to STANDARD and down to CUSTOM.

Files are byte-for-byte copies of the supplied originals.
