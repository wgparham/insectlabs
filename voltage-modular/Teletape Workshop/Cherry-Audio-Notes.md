# Teletape Workshop — Cherry Audio Notes

Short module descriptions for the Cherry Audio Notes fields. Versions and descriptions follow the current Teletape Workshop canonical list.

## RVG Random Voltage Generator — 1.8.0

RVG creates two independent stepped random voltages with variable event timing, manual and external reselection, and a +4 V trigger output. Set the three-position hold switch for clean compensated output, gentle factory drift, or stronger failure-style droop.

## b08 Blanking Panel — 1.0.0

b08 is an 8 HP visual blanking panel for filling unused rack space, with Teletape Workshop branding and tape-reel artwork. It has no custom DSP or functional controls.
