# DCA 1.0.0 release notes

- First canonical DCA release.
- Two independently controlled amplifier channels with LIN / EXP / LOG gain response, ±5 V bias and +5 V-normalled CV.
- IND, SERIAL and ST modes with cable-normalled A-to-B routing and mono/stereo DUAL behavior.
- Soft level-dependent coloration and an oversampled nonlinear stage.
- The Java export, Designer-embedded source and module identity are synchronized at `dca` / `com.insectlabs.dca`; Designer Notes identify release `v1.0.0`.
- Cherry Audio publication is deferred under the Teletape Workshop publication plan.
