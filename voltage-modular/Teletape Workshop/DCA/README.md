# DCA — Dual Controlled Amplifier

DCA 1.0.0 is the canonical Teletape Workshop dual amplifier module. It combines independent channels, serial A-to-B routing, a stereo mode, a mono fold-down, unity link inputs and a shared LIN/EXP/LOG response control per channel.
