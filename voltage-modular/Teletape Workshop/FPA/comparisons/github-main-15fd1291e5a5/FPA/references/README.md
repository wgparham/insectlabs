# FPA references

This folder keeps the module-specific pedal schematics, board photographs and the design research record. The Roland RE-101/201 and RE-301 service manuals are shared with the [SM1084 delay reference archive](../../sm1084/development/delay%20reference/); FPA's extra copies were byte-identical and removed to avoid maintaining duplicates.

The [design research note](FPA-Design-Research.md) separates source documentation from schematic interpretations, modeling decisions and unresolved questions. `OverdriveShootout.webp` is marked CC BY-NC-SA 4.0 by Electric Druid; preserve its attribution and license terms if redistributing or adapting it.
