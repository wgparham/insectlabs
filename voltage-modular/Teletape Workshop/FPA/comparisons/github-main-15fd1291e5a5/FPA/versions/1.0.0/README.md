# FPA 1.0.0 — Four Pre-Amps

The first canonical FPA release. The tone control is signed from −1 to +1, with 0 centered; the C, Re and D voicings are neutral at center. The O voicing retains a low-pass response across its full tone sweep.

See [USER-MANUAL.md](USER-MANUAL.md) for operation, [DEVELOPER-NOTES.md](DEVELOPER-NOTES.md) for DSP and maintenance details, and [REVIEW.md](REVIEW.md) for validation limits and the user-authorized promotion scope.
