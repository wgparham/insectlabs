# FPA — Four Pre-Amps

Canonical version: [1.0.0](versions/1.0.0/README.md). User-confirmed functional in Designer before the signed-tone correction; the exact release candidate passed the scoped DSP and SDK checks on 2026-10-20. Cherry Audio publication remains deferred until the Teletape Workshop list is locked.

- [Canonical files and hashes](versions/1.0.0/SHA256.json)

FPA provides four independent mono preamp/overdrive voices inspired by CE-1, RE-201/RE-301, BD-2 and SD-1 circuits. These are workflow and tonal inspirations, not component-level reproductions. The DSP path, control semantics and remaining research questions are documented in the release notes and research record.
