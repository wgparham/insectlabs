# OSC 1.0.0

First canonical release, 2026-10-17. The user approved native operation and sound, including the dedicated V/oct and through-zero linear FM addition.

- Simultaneous shaped sine, triangle/ramp and pulse; individual levels and direct mix.
- Audio and low-frequency ranges, row CV with selectable destinations, common phase/drift and intentional level/DC interactions.
- 4x synthesis, band-limited waveform banks and two-stage output decimation.
- Housekeeping standardizes descriptive identifiers and output tooltips, removes draft Designer Notes, and sets exact Notes `v1.0.0`; UUIDs, panel, saved state, assets and DSP remain preserved.
- Canonical pair, final hero, manual, developer notes, design/research evidence, tests and hashes are retained. Reusable waveform helpers are in DSP primitives. Prototype measurements remain research; obsolete working pairs/backups are removed after archive validation.

Cherry Audio publication is deferred until the full Teletape Workshop lineup is locked and canonized. No publication or Git push is implied by this local promotion.
