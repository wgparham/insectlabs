# Historical OSC prototype evidence

Retained metrics/notes describe discarded development candidates. Embedded source hashes identify those historical exports; they are not claims about the canonical pair. The 2x candidate's fast modulation errors motivated the 4x design. Prior pre-linear-FM measurements predate the separate pitch jack. The active release is [OSC 1.0.0](../../versions/1.0.0/README.md); obsolete executable pairs are intentionally not retained.
