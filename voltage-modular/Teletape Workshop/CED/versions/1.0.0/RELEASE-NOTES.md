# CED 1.0.0

First canonical release of CED Chorus Ensemble Device.

- Combines four complementary Dimension-style stereo delay programs with a CE-1-style chorus/vibrato voice.
- Adds three selectable multi-program combination laws, exclusive selection, rate/depth CV, adjustable delay noise, and optional modeled compander.
- Exposes input drive and rate/intensity controls for the CE-1-style path without an output attenuator.
- Uses a shared allocation-free chorus core for both modes; each mode has a distinct bandwidth and signal path.
- Host bypass provides direct normalized routing and holds DSP state; changing modes clears stale wet history.

The control panel, source pair and release behavior are captured in this version archive. See `REVIEW.md` for evidence and limits.
