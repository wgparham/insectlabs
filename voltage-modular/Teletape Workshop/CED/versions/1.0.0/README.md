# CED Chorus Ensemble Device — 1.0.0

CED combines a four-program stereo Dimension-style ensemble with a mono CE-1-style chorus/vibrato path. The implementation draws on published service material and circuit readings, then makes explicit workflow extensions; it is not an exact Roland clone.

- [Developer notes](DEVELOPER-NOTES.md)
- [Review and validation](REVIEW.md)
- [SHA-256 inventory](SHA256.json)

The release is self-contained: `ced.java`, `ced.vmod`, and `ced_hero.png` are the matching canonical files. Repeatable source and DSP tests are in `tests/`. The user-supplied `ced_hero.png` is the approved panel reference.
