# CED — Chorus Ensemble Device

CED combines a four-program Dimension-style stereo ensemble with a CE-1-style chorus/vibrato voice. The current canonical archive is [version 1.0.0](versions/1.0.0/), with its [manual](versions/1.0.0/USER-MANUAL.md), [developer notes](DEVELOPER-NOTES.md), and [research summary](research/Design-Research.md).

Publication is deferred with the rest of Teletape Workshop until the complete series lineup is locked.
