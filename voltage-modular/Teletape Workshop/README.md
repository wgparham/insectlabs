# Teletape Workshop

Teletape Workshop is the new name for the planned Radiophonic series. It follows the completed Wardenclyffe Station collection and shifts toward electronic-music studio equipment rooted in the mid-1960s through mid-1970s. The direction is accepted; no complete module inventory, sequence or individual brief is locked.

## Accepted directions to explore

- More common CV control, including voltage-controlled switching.
- Modern manual switches and routers for studio performance.
- Studio contour and filtering tools, including a possible active Baxandall design distinct from Wardenclyffe’s passive 21-24eq.
- A frequency shifter with separate UP and DOWN outputs.
- External sample-and-hold or track-and-hold, and tape/delay/reverb instruments.
- An EMS-inspired random-voltage instrument, with two random channels and variable timing among the ideas to evaluate.

These are design directions, not a committed product list. Keep the general CV reference at +5 V unless a future module brief establishes a specific reason to use another scale.

## Current work

`RVG/development/` is the only current Teletape module folder. It contains a rough Designer project, exported Java and EMS reference files. The current pair is an early scaffold rather than a build-ready candidate: its exported class and display name are still `MyModule`, the Designer Notes field is blank, and the RVG behavior has not been agreed as a specification. The mockup and reference notes are the starting point for the next design discussion. No Teletape module is canonical yet.
