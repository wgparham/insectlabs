# Teletape Workshop design resources

Series-level visual assets and typography used by Teletape Workshop panels.

- [Audio tape-reel SVG](Teletape_Workshop_audio_tape_reel.svg) — artwork used by the b08 blanking panel.
- [Overlapped TTW wordmark](Teletape_Workshop_TTW_overlapped.svg) and [RGB TTW wordmark](Teletape_Workshop_TTW_RGB.svg) — Teletape Workshop mark variants.
- [QT Future Poster font](fonts/QT%20Future%20Poster/QTFuturePoster.otf) — display typeface retained with its original [license text](fonts/QT%20Future%20Poster/COPYING-QUALITYPE). The license offers SIL Open Font License 1.1 or GNU GPL 2.0-or-later; retain the license alongside redistributed font copies.

The Designer project embeds its own image resources. These originals are kept here as editable series assets and should not be replaced by extracted copies from a module archive.

The [SHA-256 manifest](SHA256.json) covers these retained assets and this inventory, excluding the manifest itself.
