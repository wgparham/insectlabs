# Teletape Workshop blank panel template

A minimal front-panel-only Voltage Module Designer starter, with the Teletape panel artwork and no custom DSP, controls, jacks or user audio callback. Copy the matched `blank.java` and `blank.vmod` pair into a new module development folder before adding a panel. The pair is preserved from the user's clean Teletape blank and remains a template rather than a published module.

`SHA256.json` records both source files and this inventory. Confirm the `module code` block matches the Java export after Designer changes.
