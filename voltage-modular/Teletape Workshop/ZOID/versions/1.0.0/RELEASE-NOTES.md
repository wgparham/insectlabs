# ZOID 1.0.0 — 2026-10-16

First canonical release of the streamlined Synthi 100-inspired trapezoid generator.

- One shared Delay/Attack/On/Decay clock drives two segment-rotated outputs.
- All four time stages use the documented 2 ms–20 s range and a common exponential control curve.
- Added the final five-mode trigger workflow, bipolar output level controls and logarithmic envelope VCA.
- EOA and EOC outputs are 5 ms, +5 V pulses.
- Final module class and filenames are `zoid`.
- Cherry Audio publication is deferred until the Teletape Workshop series is complete.
