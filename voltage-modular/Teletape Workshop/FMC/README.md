# FMC — Four Channel Modulator

FMC is a four-lane modulation and delay module with selectable BF-2-style flanger, TR-2-style tremolo, DM-2-style analog delay and DD-2-style digital delay voices. The four lane outputs stay independent, with a half-sum MIX output. Cherry Audio publication remains deferred with the rest of Teletape Workshop.
