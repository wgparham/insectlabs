# FMC 1.0.0 release notes

- Establishes the first canonical Four Channel Modulator build with four selectable voices: BF-2-style flanger, TR-2-style tremolo, DM-2-style analog delay and DD-2-style digital delay.
- Preserves the supplied four-lane panel and distinct BF/TR/DM/DD defaults.
- Aligns the exported Java and embedded VMOD sources, release notes field, component source names and human-readable display names; adds voice-aware parameter tooltips and typed-entry conversion checks.
- Corrects the SDK edit callback to run once and keeps the direct-input and half-sum MIX paths defined during host bypass.
- Archives FMC pedal/pedal-circuit references, build documentation, repeatable SDK/DSP/wiring/VMOD validation and a headless CPU microbenchmark.
- Cherry Audio publication remains deferred until the Teletape Workshop lineup is locked.
