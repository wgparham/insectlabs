# SW3 1.0.0

First canonical release of the two-path Voltage Controlled Switch. The archive promotes the supplied v0.1.7 pair without DSP changes. The Designer Notes field now contains only `v1.0.0`; obsolete sketch notes were transferred into the manual and maintenance documentation. The exponential FADE mapping, gate/latch logic, panel artwork, saved-state behavior, and route design are retained.
