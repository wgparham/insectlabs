# RVG Random Voltage Generator

**Canonical release: v2.0.0.** An EMS-inspired random-voltage source for musical modulation. It provides two independent stepped outputs, randomized event timing, manual and external reselection, and a trigger output. It models the RVG's workflow and character; it is not a component-level circuit reconstruction.
