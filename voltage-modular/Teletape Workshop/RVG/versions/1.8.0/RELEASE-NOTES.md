# RVG release notes

## v1.8.0 — 2026-10-12

First canonized Teletape Workshop release. RVG provides two independently sampled bipolar voltage outputs, randomized event timing, Mean CV, manual and external reselection, inhibit/free-run control, a +4 V trigger, and a three-position hold character switch. FACTORY (middle) is the saved startup mode. User-tuned droop is 15 mV/s in FACTORY and 115 mV/s in BLOWN CIRCUIT.

This release models the RVG's workflow and response rather than reconstructing its circuit. No RVG schematic or measured EMS droop specification is claimed. See [Developer Notes](DEVELOPER-NOTES.md) for implementation details and [Release Review](REVIEW.md) for validation and approval evidence.
