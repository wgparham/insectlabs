# CXL 1.0.0 — 2026-10-18

First canonical release of the CXL Algorithmic Reverberation.

- One modulated, cross-coupled stereo plate-style tank with separate stereo injections and distributed stereo pickup taps.
- DECAY spans 0.8–5 seconds in UP/12-bit mode and 3–30 seconds in DOWN/extended mode, with a shared 3–5 second comparison range.
- The extended converter step is set to the 180-level midpoint between earlier 8-bit and 9-bit audition settings. The user preferred this balance of audible grain and tonal clarity.
- PRE-DELAY, independent high-frequency damping, wet-only input drive, dry/wet mix and final output amplitude controls.
- Direct host bypass, mono-normalled inputs and selectable stereo/mono output routing.

The implementation is an original design informed by EMT 140 documents and Dattorro's published plate topology. No component-exact EMT or Lexicon reconstruction is claimed. Publication to Cherry Audio is deferred until the collection lineup is complete.
