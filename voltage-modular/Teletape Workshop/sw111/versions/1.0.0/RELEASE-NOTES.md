# swCXI 1.0.0

First canonical release of the ten-stage sequential switch. The supplied v0.1.2 active DSP and panel are retained, including every-sample cable writes, routed-input reads, CV selection across the knob's active stage count and the short exclusive handoff. Code cleanup adds clear stage names and a mode-aware SEL tooltip. The confirmed knob range is clockwise 1-10, default 1. Direct host bypass freezes histories and resumes without replaying edges or fading state.

The old 16-way bidirectional proposal was abandoned. This module has dedicated input/output jacks and two simultaneous opposite signal routes. Cherry Audio publication remains deferred.
