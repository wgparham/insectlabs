# SVF — canonical 1.0.0

The [SVF 1.0.0 release](versions/1.0.0/README.md) exposes HIGH, BAND and LOW taps from the documented Synthi 100 HPF state-variable core, with two independently controlled channels. The product combines the planned HPF/LPF/BPF roles as a dual three-output filter. It does not claim to reproduce every Synthi 100 revision or the separate 34/00 LPF board.

The current working pair remains in [development](development/README.md). Shared Synthi filter research, original scans, photos and demonstrations are catalogued under [series references](../references/Synthi-100-Filters/INITIAL-RESEARCH.md). The repeatable circuit/code checks live with the release.
