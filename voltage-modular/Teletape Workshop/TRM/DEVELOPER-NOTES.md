# TRM developer notes — 1.0.0

Canonical Teletape Workshop module: **TRM Triple Ring Modulator**, Java class `trm`, package `com.insectlabs.trm`, Processor category. Canonical source pair and hero are `versions/1.0.0/trm.java`, `trm.vmod` and `trm_hero.png`. The editable Designer source is in `development/`. See the [user manual](USER-MANUAL.md), [release review](versions/1.0.0/REVIEW.md), [validation record](versions/1.0.0/VALIDATION.txt) and [DSP design record](versions/1.0.0/DSP-DESIGN.md).

Each of the three lanes has Carrier and Modulator gains from 0 to 2, defaulting to unity, a four-position T/G/S/Si switch, a level lamp and an output. Selector defaults are lane 1 S (state 2), lane 2 G (state 1), lane 3 Si (state 3). The defaults are intentionally staggered for immediate access to different voices. The lamp tracks the larger absolute gain-staged input and is scaled against 5 V.

`ProcessSample` reads three independent input pairs, smooths gains at a 5 ms time constant, tracks each pair's max absolute level with 8 ms attack and 120 ms release, processes the selected mode, decimates the 2× nonlinear path, normalizes the FIR DC response and writes the output and lamp. `processRingCore` contains the four voices; `transformerTransfer`, `softConduction`, `hardConduction` and `softClip` implement the shaping curves. `processModeTransition` crossfades selector changes over approximately 5 ms at twice the native sample rate. Each lane owns independent carrier/modulator upsamplers and output downsampler.

There is no output control, automatic makeup gain, final limiter or dry path. Host bypass skips reads, silences outputs/lamps and freezes histories. Resume clears FIR state and immediately adopts current gains and selector positions. Signal guards bound finite inputs and convert nonfinite values to silence. Processing arrays and FIR buffers are allocated outside the sample callback. CPU was not benchmarked on the target host; the six FIR streams, nonlinear functions and multiple mode evaluations during transitions are the main costs.

The embedded `HalfBand19` arithmetic and coefficients match the shared [DSP primitive](../../../dsp-primitives/src/com/insectlabs/dsp/filters/HalfBand19.java) bit-for-bit. The self-contained copy is retained in the VMOD so the module does not depend on external Java classes at build time. Preserve its arithmetic and coefficients during routine cleanup. For code changes, rerun [the validation harness](versions/1.0.0/tests/validate.py), review its [record](versions/1.0.0/VALIDATION.txt), and perform native build/listening checks for audible changes.
