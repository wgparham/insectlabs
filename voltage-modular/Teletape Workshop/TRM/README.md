# TRM Triple Ring Modulator

**Canonical release: 1.0.0.** Three independent ring-modulator lanes with per-input gain staging and four distinct, envelope-responsive voices. The component palette is an EMS-inspired creative interpretation, not a component-exact EMS reconstruction.
