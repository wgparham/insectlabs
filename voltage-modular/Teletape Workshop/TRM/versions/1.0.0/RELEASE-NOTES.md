# TRM release notes

## 1.0.0 — 2026-10-15

- First canonical TRM build with three independent gain-staged ring-modulator lanes.
- Added four envelope-responsive T/G/S/Si voices with distinct saturation and conduction behavior.
- Preserved three different selector startup positions for immediate access to S, G and Si.
- Added per-lane input-activity lamps, 2× nonlinear processing and click-reduced mode crossfades.
- Canonized after user listening and functional approval. No Cherry Audio publication; collection publication remains deferred.

- 2026-10-20: Cosmetic panel refresh updates the logo skin/image references; DSP and control behavior are unchanged.
