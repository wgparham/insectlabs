# SN93T — Tuner

Canonical version: [1.0.0](versions/1.0.0/). The module provides monophonic pitch detection, multiple tuning systems, reference tone output and a VCO calibration sweep. Read the [user manual](versions/1.0.0/USER-MANUAL.md), [developer notes](versions/1.0.0/DEVELOPER-NOTES.md) and [release review](versions/1.0.0/REVIEW.md).

Historical design notes are kept in [`research/`](research/). Repeatable code and tuning tests are part of the canonical release folder.
