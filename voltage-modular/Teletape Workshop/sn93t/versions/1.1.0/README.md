# SN93T 1.1.0 — Tuner

Second canonical release. This version standardizes the external jack voltage ranges: TONE output is 5 V peak at the 0 dB setting and Cents CV is ±5 V at ±50 cents. The detector sensitivity and pitch/CAL CV mappings remain unchanged. The control layout is unchanged; the Designer save refreshed its module skin and logo resource IDs. The archived [1.0.0 release](../1.0.0/) remains intact.

See [user manual](USER-MANUAL.md), [developer notes](DEVELOPER-NOTES.md), [change record](CHANGELOG.md), and [release review](REVIEW.md).
