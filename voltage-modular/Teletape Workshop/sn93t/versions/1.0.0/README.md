# SN93T 1.0.0 — Tuner

The first canonical SN93T release. It provides monophonic pitch detection, reference tone, tuning maps, CV outputs and VCO calibration. The exported Java source and Designer project are preserved together in this release folder.

See [USER-MANUAL.md](USER-MANUAL.md) for panel operation, [DEVELOPER-NOTES.md](DEVELOPER-NOTES.md) for implementation behavior and maintenance, and [REVIEW.md](REVIEW.md) for validation results and limits.
