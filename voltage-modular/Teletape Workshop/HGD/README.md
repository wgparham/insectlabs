# HGD — High Gain Device

HGD is a four-lane, mono high-gain processor. Each lane offers an independent gain stage, tone control, selectable distortion voice and output. A fifth output provides a half-sum of the four processed lanes.

The first canonical build is [HGD 1.0.0](versions/1.0.0/). See the [user manual](versions/1.0.0/USER-MANUAL.md), [developer notes](DEVELOPER-NOTES.md), and [release review](versions/1.0.0/REVIEW.md).

The four software voices draw on DS-1, Maestro Fuzz-Tone, HM-2 and MT-2 circuit references. They are distinct modeled instruments, not exact hardware reproductions. Supporting files are retained in [HGD references](references/README.md).
