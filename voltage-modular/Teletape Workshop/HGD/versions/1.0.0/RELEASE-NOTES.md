# HGD 1.0.0 release notes

- Establishes the first canonical High Gain Device build with four independent lanes and DS, FZ, HM and MT voices.
- Keeps the supplied panel and DSP behavior. The Java export is synchronized into the Designer project, whose Notes field now records `v1.0.0`.
- Makes the Gain value presentation consistent across all four controls and gives the top III label and Designer guide lines descriptive names. These are UI/metadata cleanups; nonlinear DSP methods and coefficients are unchanged.
- Archives HGD-specific pedal reference files, user/developer documentation, and a repeatable SDK/DSP validation harness.
- Cherry Audio publication remains deferred until the full Teletape Workshop lineup is locked.
