# HGD reference files

These files were collected with the HGD development set and are preserved here as design research for its DS, FZ, HM and MT voices. The received filenames are kept unchanged. Source URLs and license details were not included with every local image/document; do not present them as primary provenance without checking the source page.

| File | Use in the HGD research |
|---|---|
| `boss-ds1-board.png`, `boss-ds1-distortion-pcb.jpg`, `boss-ds1-distortion-schematic.webp` | DS-1 board and circuit reference |
| `boss-ds1a-board.png`, `boss-ds1a-distortion-pcb.jpg`, `boss-ds1a-distortion-schematic.webp` | DS-1A board and circuit comparison |
| `boss-fz-1w.png`, `maestro-fz1-figure2.svg`, `Master-Fuzz-1v1-Building-Docs-1.pdf` | FZ-1/Fuzz-Tone-era reference material |
| `boss-hm2-heavy-metal-schematic.webp`, `hm2-board.webp` | HM-2 circuit and board reference |
| `boss-mt2-metal-zone-schematic.webp` | MT-2 circuit reference |
| `boss-tr2-tremolo-schematic.webp`, `tr2-board.jpg` | Retained adjacent pedal research; HGD does not currently implement a tremolo voice |

The module's design notes distinguish source-supported observations from modeled or guessed behavior. The DSP is an interpretive four-voice instrument, not a circuit-faithful reconstruction.
