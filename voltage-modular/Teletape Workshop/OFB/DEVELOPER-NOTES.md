# OFB 1.0.0 — Developer notes

Teletape Workshop; class ofb, package com.insectlabs.ofb; Filters category. Canon is OFB/versions/1.0.0/ofb.java, ofb.vmod and ofb_hero.png. USER-MANUAL.md, RELEASE-NOTES.md, REVIEW.md and VALIDATION.txt accompany the archive.

Initialize configures sixteen fixed biquads and eight control/CV/output arrays. ProcessSample runs eight independent second-order HP then LP cascades at 48 kHz. BiquadFilter.configure derives prewarped natural frequencies from the source component arrays; section Q is sqrt(10)/2. Direct-form-I histories have finite-state recovery. Main mix signs are [-,+,-,+,-,+,-,+], following the two-summer circuit. Nominal 10k input weights are used; the PCB's 18k low-band trim is not modeled. Detailed provenance and component values remain in OFB/references/SCHEMATIC-ANALYSIS.md and derived-band-values.json.

Eight normalized 0–1 knobs default full. mixGainForKnob uses a=(100^p-1)/99, gain=a/(1+0.5*a*(1-a)), an approximate log pot and 5k/10k loading. Tooltips and typed entry use knob percent. Unpatched controls smooth gain over 5 ms; patched controls smooth manual position over 5 ms, add CV/5, clamp 0–1, then apply the taper. CV itself is immediate. Cached positions avoid repeated conversion. These smoothing paths differ during manual movement, agree at steady settings. Band taps are independent of level/CV; nonfinite input and CV become zero.

shapeMix uses y=x/(1+(x/12)^4)^(1/4), with reciprocal arithmetic above the knee to avoid overflow. It has unity small-signal gain and symmetric soft compression. This 12 V headroom is a chosen musical model, not measured 741 behavior. Aggregate mix is numerically bounded to +/-1,000,000 V before interpolation. Only this final shape is oversampled 2x to 96 kHz using embedded established HalfBand19 coefficients and DC normalization. Filters and CV remain at 48 kHz. FIR rejection and ripple are finite; upstream audio-rate modulation is not alias-free. Main nominal delay is nine native samples; tapDelay aligns each clean band by nine samples.

ProcessBypassedSample passes finite input directly, silences taps, skips knobs/CV and freezes histories. Atomic resetPending/resumePending flags queue reset, preset/variation completion and bypass return to the audio callback. Filters, resetMixer FIR/delays and gain caches reset/adopt controls on the next active sample. Native controls persist; transient history is not serialized. super.Destroy executes once.

Callbacks allocate no objects; coefficients are computed once and gain conversion is cached. Native CPU has not been benchmarked. Model omissions include actual pot curve, component tolerances, output-capacitor/load behavior, op-amp bandwidth and slew. Preserved HalfBand19 formatting is an exception to uniform local formatting, preserving established primitive arithmetic. No new test audio exists; HalfBand19 already resides in dsp-primitives, and this component-specific band network stays with OFB.

User approved sound/function and canonization 2026-10-14. The latest Designer save was preserved. A replacement-character tooltip mismatch was repaired during source synchronization; Notes finalized to v1.0.0. DSP and artwork were not changed. Both source forms and actual-callback tests are checked from the archive; see VALIDATION.txt. Detailed native automation, undo/recall UI and CPU remain independently unmeasured.

For future edits, repeat source-pair/metadata/hash checks, both SDK compilations and response/CV/state tests. Changes to components, polarity, taper, CV law, smoothing, knee, FIR phase or delay require a new listening candidate. Do not overwrite this release for audible changes.
