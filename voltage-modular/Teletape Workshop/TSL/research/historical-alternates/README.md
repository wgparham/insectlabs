# TSL historical alternate candidates

This archive preserves the rejected `tsl_alt` implementation and the exact source snapshots used during rate-mapping experiments. These are not canon and should not be used as the current implementation. The approved TSL source is [version 1.0.0](../../versions/1.0.0/README.md); the rationale and test chronology are in [Development-History.md](../Development-History.md).

`DEVELOPER-NOTES-alt.md` describes the alternate candidate. The collection-level [historical checksum record](../SHA256-alt-historical.json) identifies the restored alternate pair. The text-suffixed files in `integration-backup/` are binary/source snapshots whose bytes retain the recorded hashes.
