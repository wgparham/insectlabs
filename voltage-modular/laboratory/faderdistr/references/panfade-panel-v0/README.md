# Pre-Fader|Distr panel mockup

This is the original three-jack Panfade panel supplied before the module was reframed as Fader|Distr.
It is retained as a visual and Designer-project reference only. It does not represent the current
module topology and must not be used as a development baseline.

Both Fader|Distr A and B are now canonical; use the [current module overview](../../README.md) to find their release. This prototype is not an active development pair.
