# Fader|Distr

Fader|Distr A and B are canonical in [version 1.0.0](versions/1.0.0/README.md). Their release
folder contains the immutable matched Designer/source pairs, panel images, and checksums.

Both modules use one large BIAS dial for two simultaneous mono functions: FADER crossfades X/Y to
Z, while DISTR distributes S between 1 and 2. A is fixed linear and has the heavier, woollier
relay voice. B is fixed equal-power with a related, more open later-model voice. There is no CV
input or law switch.

The retained `prototype`, `tests`, and `references` folders document development history and support
future work. Do not modify the release in place; start a separate development copy for a revision.
