# AC/1D SIN-SQR Function Generator

Canonical version: [1.0.0](versions/1.0.0/README.md), approved 2026-09-30.

A dirty, hand-built laboratory sine/square source inspired by the Heathkit AG-10 family. It has independent sine and square boards, a shared calibrated output-frequency display and multiplier, separate level/range stages, variable square width and restrained high-level output character.
