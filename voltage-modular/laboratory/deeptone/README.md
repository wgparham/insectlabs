# 1A-30 Deep Tone Generator / Modulator

Canonical version: [1.0.0](versions/1.0.0/README.md), approved 2026-10-01.

Mono sine/beat source, linear FM, deep amplitude modulation and continuous Courtesy output. OFFSET spans +/-65 Hz with a fifth-power taper; Beat, Swell and Courtesy use the approved distinct reset smoothing.

Use the [canonical Designer project](versions/1.0.0/deeptone.vmod). See the [release review](versions/1.0.0/REVIEW.md) for validation and documented exceptions.
