# r195L: SIN/RND generator

Canonical version: [1.1.0](versions/1.1.0/README.md), approved 2026-09-30.

Mono laboratory sine/noise source with C4 tuning, moderated random FM, direct white/filtered-noise modes and a patchable FLT audio path. In FLT with MOD IN connected, MOD LEVEL is a ±200% input attenuverter/amplifier and RND MOD blends noise before filtering. Use the [versioned Designer project](versions/1.1.0/sinrnd.vmod).
