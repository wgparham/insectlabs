# Panfade

Next Laboratory project. The supplied `panfade.java` and `panfade.vmod` mockup files have been moved intact into `development`.
They are work in progress and have not been validated as a release.

Approved direction: two separate modules with matching panels, one linear and one equal-power.
Manual controls only; no CV or law switch. Preserve simultaneous parallel panning and fading,
mono-first routing, low CPU use, and the shared Colorbox bypass convention.

See the [utility specification](../../docs/Series-One-Utilities.md) and
[infrastructure standards](../../docs/Module-Infrastructure-Standards.md).
