# Burstgen 1.0.0

Canonical first release of the two-channel counted Tone Burst Generator for Voltage Modular. Burstgen alternates two live inputs using independent clock-tick counts, separate PASS/GATE outputs, a summed gated output, and independent internal CLOCK and RAMP Courtesy outputs.

The release includes eleven external clock ratios (/8 through ×7), three internal ranges, EXT/BOTH ratio routing, adaptive de-clicking that stops at fast clock rates, and direct host bypass.

See [USER-MANUAL.md](USER-MANUAL.md) for operation, examples and limits. The approved panel is [burstgen_hero.png](burstgen_hero.png).
