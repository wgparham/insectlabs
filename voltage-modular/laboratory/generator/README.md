# Generator

Canonical version: [1.0.2](versions/1.0.2/README.md), approved 2026-09-30.

Manual sine/variable-triangle laboratory source with internal/external linear FM, a hot output stage,
and a separate 1 kHz reference. Version 1.0.2 adds an 8 ms physical POWER fade while retaining the approved oscillator behavior. Use the [versioned Designer project](versions/1.0.2/generator.vmod).
