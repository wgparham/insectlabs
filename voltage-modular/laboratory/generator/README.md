# Generator

Canonical version: [1.0.1](versions/1.0.1/README.md), approved 2026-09-30.

Manual sine/variable-triangle laboratory source with internal/external linear FM, a hot output stage,
and a separate 1 kHz reference. Version 1.0.1 adds duty-cycle smoothing, cleaned code, readable Display
Names and corrected tooltip entry. Use the [versioned Designer project](versions/1.0.1/generator.vmod).
